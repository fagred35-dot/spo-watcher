# Задача для агента: улучшить UI приложения «СПО-Вотчер»

## Контекст

Windows-приложение на **C# WinForms + WebView2 (.NET 6)**. Открывает сайт техникума (`spo.rso23.ru`) внутри себя, автологинится, раз в час проверяет оценки и раз в день шлёт расписание в Telegram через сервер на Render.

**Тебе: улучшить только внешний вид. Логику, парсинг, автологин, отправку — НЕ трогать.**

## Что уже есть

- Тёмная тема приложения (`app/Theme.cs` — палитра).
- Кастомные кнопки (`app/ModernButton.cs`) — скругление, hover.
- Тёмная тема сайта внутри WebView2 (`app/site-dark.css`, инжектится на каждой навигации).
- Тёмный лог внизу окна.

## Файлы, которые МОЖНО править

| Файл | Что там |
|---|---|
| `app/Theme.cs` | Палитра цветов. |
| `app/ModernButton.cs` | Кастомная кнопка. |
| `app/MainForm.cs` | Главное окно. **Правь только визуал** — Controls.Add, размеры, паддинги, шрифты, цвета. **НЕ трогай методы** `RunGradesCheckAsync`, `SendAllGradesAsync`, `SendTomorrowLessonsAsync`, `OnNavigationCompleted`, `InitAsync`, `NavigateTo`. |

## Чего НЕ делать

1. Не менять логику работы, порядок вызовов, имена методов.
2. Не удалять кнопки. Их шесть: «Все оценки сейчас», «Расписание на завтра», «Оценки», «Расписание», «Главная», «Настройки».
3. Не трогать кнопку «Войти» на сайте (оранжевая, так задумано).
4. Не коммитить секреты, `config.json`, `credentials.dat`.

## Что улучшить (по словам пользователя)

«UI простоват, выглядит как приложение из 2000-х». Уже сделана тёмная тема и ModernButton, но есть куда расти:

- **Статус-бар:** «Последняя проверка: 19:24», «Следующая: 20:24», индикатор связи.
- **Лог:** сворачиваемый, или отдельной вкладкой (сейчас 130px внизу всегда виден).
- **Иконки** на кнопках (эмодзи или нарисованные).
- **Группировка** верхней панели: действия / навигация / настройки.
- **Минимальный размер окна.**
- **Иконка приложения** (.ico + `<ApplicationIcon>` в csproj).
- **Заголовок окна** с версией.
- **Трей** — сворачивание в системный трей.

## Сборка и запуск

```cmd
cd app
dotnet build -c Release
.\bin\Release\net6.0-windows\win-x64\spo-watcher.exe
```

**Перед сборкой убей запущенный exe**, иначе `file is being used by another process`:

```cmd
taskkill /F /IM spo-watcher.exe
```

## Требования

- Windows 10/11, .NET SDK 6.0+, WebView2 Runtime (всё уже стоит).
- NuGet качать не надо — пакеты в кэше.

## Осторожно

- **`write_file` иногда теряется** — проверяй `stat`/`read_file`.
- **`edit_many` может падать** с `EARGS` — надёжнее `write_file`.
- **`start_process` в PowerShell требует `.\`** перед exe, лучше `shell: "cmd"`.
- **CSS для Angular-сайта** может не подхватиться из-за inline-стилей — нужен `!important`.
- **Коммит:** `git add . && git commit -m "..." && git push`. Репо: https://github.com/fagred35-dot/spo-watcher
